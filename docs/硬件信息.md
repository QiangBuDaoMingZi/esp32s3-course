# 开发板硬件信息

适用：ESP32-S3 N16R8 课程开发板。此页提供基础硬件资料，具体软件参数以已发布示例为准。

首课使用 GPIO13 控制屏幕背光，高电平点亮。完整操作见 [首课说明](../examples/01_gpio_output/README.md)。

## 主控与板载器件

| 项目 | 型号 / 配置 |
| --- | --- |
| 主控 | ESP32-S3 N16R8，16 MB Flash、8 MB PSRAM |
| 温湿度 | AHT20，I2C 地址 0x38 |
| 六轴 IMU | LSM6DS3TR-C，I2C 地址 0x6A |
| 显示屏 | HXR20062C21 / ST7789T3，物理分辨率 240×320 |
| 触摸 | CST816 兼容协议，I2C 地址 0x15 |
| 音频 | ES8311，I2C 地址 0x18；NS4150B 功放、ZTS6216 麦克风 |
| RGB | 5 颗 WS2812B-2020-V6 |
| 其他 | 旋转编码器及按压、光敏电阻、microSD 卡座 |
| USB 转串口 | CH343P |

## 引脚速查

编号为芯片 GPIO，不是排针脚号。

| 功能 | GPIO / 连接 |
| --- | --- |
| 公共 I2C | SCL=1、SDA=2 |
| IMU 中断连接 | INT1=42 |
| LCD | SCLK=47、MOSI=48、CS=45、D/C=39、RST=21、TE=14；无独立 MISO |
| 屏幕背光 | GPIO13，高电平导通 |
| 触摸 | 与传感器及 codec 共用 I2C；RST=40、INT=38 |
| 编码器 | A=17、B=15、按压=16；按下低有效 |
| 光敏 | GPIO18，ADC2 通道 7 |
| WS2812 | GPIO41 → LED1 → LED2 → LED3 → LED4 → LED5 |
| 音频 I2S | DO=4、WS=5、BCLK=6、MCLK=7、DIN=8 |
| microSD | CLK=10、CMD=9、D0=11、D1=12、D2=3、D3=46 |
| 原生 USB | D-=19、D+=20 |
| UART0 | TX=44、RX=43；经 CH343P 连接 |
| 下载 / 复位 | BOOT=GPIO0、RST=EN |

## 硬件约束

- GPIO35～37 与 N16R8 模组 PSRAM 共用，启用 PSRAM 时不能同时作为排针引出的普通 GPIO 使用。
- LED6 是电源指示灯；LED7 与编码器按键共用 GPIO16，低电平点亮。
- 扬声器接口 1=SPK-、2=SPK+，SPK- 不是 GND。
- SD 外部上拉不能由软件内部上拉配置推定；接线以原理图和实物为准。
